# Development Roadmap

### Phase 1: Ingestion & Listing Monitor
- [ ] Email Webhook & IMAP parser for StreetEasy instant alerts
- [ ] Local SQLite database for listings & deduplication
- [ ] Configurable search criteria (neighborhoods, max rent, min bedrooms)

### Phase 2: AI Evaluator & Scoring Engine
- [ ] LLM prompt pipeline to extract amenities, fee structure, and red flags
- [ ] Net-effective vs gross rent calculator
- [ ] Transit / commute scoring logic

### Phase 3: Mobile Bot & Notification Dispatcher
- [ ] Telegram Bot with instant push alerts and action buttons (Approve / Pass)
- [ ] Tenant Resume generator (income ratio, credit score, move-in date)

### Phase 4: Outreach Automation & Inbound Tour Handler
- [ ] Automated form / email inquiry dispatcher
- [ ] Inbound reply parser for tour availability
- [ ] Calendar integration for viewing slots
